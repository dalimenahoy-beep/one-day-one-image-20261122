# One Day, One Image — Sunday 22 November 2026

A single-image front page of the world's news for **Sunday 22 November 2026**, drawn entirely in code: *The World Gazette* leads with the COP31 climate summit in Antalya ending without a deal, joined by the Dymer strike rescue, the sinking of the Russian corvette Merkury at Benghazi, the Iran strike on Bahrain with tankers ablaze near Hormuz, the Democrats' 258-seat House majority, the Banten candy-factory fire, the capture of 'El Chapo Isidro', Asia's AI-stock sell-off, and BepiColombo's arrival at Mercury — twelve stories across seven regions, plus a day-in-numbers box and a wire ticker.

The program (`main.ts`) writes its embedded Python renderer (`make_poster.py`, Python/PIL) to a temp file, runs it, and places the finished poster (`entry.png`, 1024×1024) at `/output/entry.png`. No network, no clocks, no randomness — every run writes identical bytes.
